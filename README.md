# Bubbles 🫧

**Play it: <https://bubbles.3m4.net>**

A fruit-popping arcade mini-game. Bubbles rise from the bottom of the screen;
pop the fruit before the clock runs out, avoid the vegetables, and chain
streaks for bonus points.

The site ships two versions of the game:

| | Route | Stack |
|---|---|---|
| **Remastered** | [`/play/`](https://bubbles.3m4.net/play/) | Phaser 3 + TypeScript + Vite, original art, EN/ES |
| **Classic (2015)** | [`/classic/`](https://bubbles.3m4.net/classic/) | jQuery 1.8 + GSAP 1.13 + SoundJS 0.6, preserved as-is |

## How to play

- 🫧 **Pop fruits** — +50 pts each
- 🥦 **Avoid veggies** — −7 pts and your streak resets
- 🫐 **Grab blackberries** — +5 seconds on the clock
- 🔥 **Chain streaks** — bonus points at ×3 (+7), ×9 (+18) and ×12 (+30)

A round lasts 30 seconds, extendable up to 45 by catching blackberries.

## Development

Requires [bun](https://bun.sh).

```sh
bun install

bun run dev          # remastered game + homepage → http://localhost:5173
bun run dev:legacy   # classic game → http://localhost:8015

bun run build        # full site → dist/ (homepage + /play/ + /classic/)
```

### Voice announcer

The remaster has an AI announcer ("Let's go!", "Level up!", "Game over!",
"New high score!") voiced with [ElevenLabs](https://elevenlabs.io). The clips
are generated once and committed under `remaster/public/voices/`, so the build
and CI never touch the API. To (re)generate them:

```sh
cp .env.example .env         # then set ELEVENLABS_API_KEY in .env
bun run voices               # writes remaster/public/voices/<event>.<locale>.mp3
bun run voices --dry-run     # preview without spending credits
```

- Lines come from the `voice*` keys in `remaster/src/i18n/catalog.ts`: every
  base language, plus country variants that define their own lines (es-MX).
  Languages the model does not support are skipped, and at runtime a locale
  without clips falls back to its base language, then English. The build
  detects which locales have a complete clip set (`vite.config.ts`).
- The script skips clips that already exist. Delete an mp3 to regenerate it.
- Model `eleven_v3` with `language_code` enforced per locale and the premade
  voice "Charlie" for every language (library voices need a paid plan via the
  API). Override with `ELEVENLABS_MODEL_ID`, `ELEVENLABS_VOICE_ID` or
  `ELEVENLABS_VOICE_ID_<LOCALE>`. `bun run voices --locale es` limits a run to
  one locale.
- The script prints the credits the run consumed; the free tier gives 10,000
  characters per month.
- The mute button and volume slider at the top right of the game apply to
  sound effects and the announcer alike (saved per browser).

### Accounts and online scores

Playing never requires an account. The homepage and the game load the
[3m4 accounts](https://accounts.3m4.net) session widget (`session.js`), the
same login shared by every 3m4 app: when a session exists, the end screen
sends the score to the Bubbles API (`api/`), the homepage shows the online
top 10 with the players' handles and avatars, and your own row is
highlighted. Scores need a verified e-mail. Nothing is stored for anonymous
players except the per-browser high score.

Local development: run the accounts stack (`make up` in `~/accounts`, port
8085) and the API (`docker compose up` in `api/`, port 8000); the Vite
defaults in `vite.config.ts` point at production, so set `VITE_ACCOUNTS_URL`
and `VITE_API_URL` in `.env` for a fully local run.

### Docker

The whole site can be built and served as a container (bun build stage +
nginx):

```sh
docker compose up --build   # → http://localhost:8080
```

## Project structure

```
├─ legacy/     # the original 2015 game, kept behaviorally intact
│  ├─ scripts/copy-vendor.ts   # copies pinned libs from node_modules → vendor/
│  └─ vendor-static/           # SoundJS 0.6.0 (that version was never on npm)
├─ remaster/   # Vite multi-page app: homepage (/) + Phaser 3 game (/play/)
│  ├─ public/art/              # original SVG art (MIT, drawn for this project)
│  ├─ public/voices/           # announcer mp3s, generated by scripts/generate-voices.ts
│  └─ src/game/                # scenes: Preload, Game, End
├─ api/        # Flask + Postgres: online scores for signed-in 3m4 accounts (see api/PLAN.md)
└─ .github/workflows/deploy.yml  # bun build → GitHub Pages (bubbles.3m4.net)
```

### Notes on the legacy version

- Its libraries (jQuery 1.8.3, GSAP 1.13.2) are installed by bun at the exact
  original versions and copied into `legacy/vendor/` at build time — they no
  longer live in the repo. SoundJS 0.6.0 was never published to npm, so that
  single file is committed under `legacy/vendor-static/`.
- `javascripts/scripts.js` is a hand-compiled bundle from 2015 (jQuery 1.11.3,
  underscore, jSmart, colorbox, …). It is treated as project source.
- DataTables was removed: `index.html` never loaded it.
- The original `img/back.jpg` background was already missing from the first
  commit; a CSS gradient in the same palette stands in for it.
- Game piece templates are compiled into `json/devolverPlantillas.json` by
  `bun run plantillas` (from `legacy/`).

### Sharing

The end screen shares your score to Facebook via the share dialog. The score
travels as URL parameters (`?score=…&streak=…`) and the homepage greets
challenged friends with a banner.
